## 6. 已明确的边界与未接入的外部系统

- 站内通知已实现并记录发送日志；短信/IM 等外部通知通道未接入，`lib/notifications.ts` 可替换。
- 设备测试接口为桩实现（`lib/device-stub.ts`），返回模拟当前条码与设备 IP。
- 系统按单实例 + SQLite 验证；未做 PostgreSQL/多副本。
- 内置调度器需显式 `ENABLE_SCHEDULER=true`；也可用外部 cron 调用接口，二者只启用一种。
- 生产环境需要替换默认密钥并启用 HTTPS；见部署手册。
